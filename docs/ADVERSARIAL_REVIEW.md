# 拾言对抗式审核 · 2026-11-05

## 结论

当前项目具备带来源、人工确认和账号隔离的个人记忆系统基础。尚不能以本次审核证明“行业顶尖”或“没有漏洞”。主要差距是语义真实性、长期冲突处理、遗忘传播和真实模型评测，不是再增加几个模型选项。

本轮先写反例，再修改实现。最初8个新攻击用例全部失败，原有53项测试当时仍全部通过。这说明旧测试的覆盖不足。修复后新增对抗及完整性测试16项，后端合计69项通过。真实模型未参与本轮测试；所有经历、攻击输入和上游响应均为虚构。

审核修复以 v1.3.1 候选版本提交评审；报告不声称该版本已经部署至 Render。GitHub Pages 是独立的本地导入可视化页面，不承载账号服务或数据库。

## 覆盖范围与方法

基于远端 `main` 的 `1be24ea4e53e76e047b69307f74c7a354384948d` 建立205个文件的清单：54个核心文件列入重点审核范围，对其中信任边界和关键逻辑分支人工检查；58个其他代码/测试文件进行静态、类型或测试覆盖检查，63个第三方组件/源码做静态检查，30个配置/文档文件检查。详见 [文件清单](AUDIT_INVENTORY.json)。清单的哈希是清单生成时的本地文件内容，不是基线提交的哈希；新增文件以PR差异为准。

重点路径：登录和验证码 → 请求账号上下文 → 原文导入 → 记忆抽取 → 证据定位与说话人归属 → 合并与确认 → 检索与模型出口 → 修订、删除和备份。另检查浏览器渲染、模型密钥、部署入口及依赖树。未手工逐行审计第三方库内部，也未进行生产数据库操作、真实付费模型攻击或公网压力测试。

威胁假设包括恶意导入文本、格式合法但语义错误的模型输出、同一用户并发更新、跨账号访问尝试和异常上游响应。方法参考 [OWASP Agent 安全指南](https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html)，它是检查参考，不代表任何认证。

## 向高水平记忆系统推进的顺序

1. **先建立可审计的事实与遗忘基础。** 版本化记忆、字段级证据、有效时间和替代关系；将“用户确认”和“外部事实可靠性”拆开呈现。先关闭SEM-01/FORGET-01。
2. **建立带标注的评测集，再更换检索。** 覆盖跨会话、同义表达、否定、改口、未知日期、无答案、提示注入和跨账号负例。分别测召回率、支持关系准确率、错误记忆写入率、冲突处理、拒答与隐私，比较基线后决定是否引入向量和重排。
3. **让规划能够被实际结果修正。** 保存计划依据版本、行动、用户反馈和修订，不把模型建议自动沉淀为事实；用后续行动是否有帮助评价产品，而不只看摘要流畅度。
4. **补容量与运营证据。** 定义租户配额、备份/恢复及删除演练、真实模型费用和性能；再开展用户试用及扩大公开注册。

建议门槛是开发目标，不是本次成绩：至少1,000条人工标注查询；Recall@10目标90%以上、引用支持关系正确率99%以上；跨账号/未授权私密/删除传播用例必须全部通过；同时报告无答案拒答表现、样本量、成本和延迟。达到这些门槛也只能说明指定评测集的结果，行业领先仍需要与公开基线和真实用户效果比较。
