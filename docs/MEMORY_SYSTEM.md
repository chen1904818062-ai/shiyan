# 拾言 · 个人 AI 记忆系统 v1.3.1 候选

将用户主动导入的对话和亲自补充的经历，沉淀为可追溯、可更新、可调用的个人记忆。当前上线目标仍为 Render + Turso，未接入外部 AI 账号的自动采集。

## 从哪里开始

1. 登录后进入「我的记忆」。没有模型密钥也可以「补充记忆」，填写经历、目标或偏好，核对后点击确认。
2. 已有聊天记录先放进「我的话题」，再到记忆档案点击「提炼记忆」。每次处理1段未提炼的对话，可继续执行。所有模型结果先保存为候选。
3. 展开证据，可以打开完整原文并查看引文高亮。角色不明的内容需要格外核对；AI 内容只能作为参考。
4. 修订会保留历史，并将记录改为已修订；重新确认后才会用于回答。「不准确」和「不再适用」都停止调用，但保留档案。
5. 「与记忆对话」支持有来源的回顾与分析；「规划与复盘」生成探索步骤和验证方式。实际行动反馈由用户填写，保存为私密候选，不会把计划当成已经发生的经历。
6. 记忆可按类型、状态筛选，按更新日期或经历时间排列。未知发生日期不补猜。超过300条可继续加载；界面筛选基于已加载内容。

## 调用范围与模型

- 默认只调用已确认的普通记忆。私密和敏感记忆需每次明确勾选允许使用；此分类控制模型调用，不改变账号归属和登录要求。
- 在全部已确认且获准使用的记忆中，用中文二元词和英文关键词匹配陈述、背景及话题，再加载最多24条及证据。无匹配时拒答，本次不调用模型。当前为SQL词面检索，未接入向量检索，无法保证找全同义表达。
- 所选记忆会发送至用户配置的模型提供商，密钥仍仅暂存页面内存。不会为了问答加载全部原文，也不会自动读其他账号数据。
- 回答、分析及行动步骤须带真实记忆ID；不存在的引用会拒绝。生成过程中来源或记忆变化则返回冲突，要求重试。结构与来源检查不能保证模型的语义判断完全正确。
- 问答不是自动执行决策。规划是建议，发生日期、记录日期和修订日期分开表达；模型不应据记录先后推断人生轨迹。
- 回答暂存在当前页面，切换功能或刷新后不保留，可导出Markdown。导出按产生该答案时的问题和证据生成。模型输出不自动写入已确认记忆。

## 数据生命周期

记忆、证据、修订分别存储；相同用户、类型、规范化陈述、明确发生日期和说话人共同确定身份，重复证据不再插入；不同日期的同名经历分别保存。并发提炼用数据库唯一约束保证不生成两个相同条目。新增独立证据会将已确认记忆转回候选并记录历史，隐私等级只在合并时升级，不会被较低等级覆盖。生成任务使用每账号数据库租约；目录读取不占用生成锁。

删除记忆会删除其证据和修订史，保留原始对话。删除一份来源时，若有其他独立证据，重新指定主来源并保留记忆；所有来源删除后记忆随之删除。已提炼的空结果也记录处理状态，避免反复付费抽取。

个人导出JSON包含记忆及证据；迁移备份v3额外包含修订、处理记录和账号数据，兼容导入v1/v2备份。迁移工具仍拒绝向非空数据库导入。

## 当前边界

尚未实现跨AI账号自动采集、向量检索、自动冲突合并、定时提醒或跨产品记忆授权接口。相互矛盾的记忆可保留，用户可修订或归档；模型应提出确认问题，不擅自宣布某条目标失效。规划和回答目前不作为独立历史记录持久化。

## 验证

本地使用临时SQLite、模拟邮件和模拟模型验证，无需真实密钥。主要命令：

```powershell
npm run build:standalone
node node_modules/typescript/bin/tsc --noEmit
node --test tests/memory.test.mjs tests/memory-system.test.mjs tests/standalone.test.mjs tests/accounts.test.mjs tests/model-config.test.mjs tests/model-catalog.test.mjs tests/summary.test.mjs
node tests/memory.browser.mjs
```

浏览器测试需配置已有Playwright模块和Chrome/Edge路径，沿用项目现有测试方式。

## 本轮审核

v1.3.1 为审核候选版本，不表示线上已更新。69项后端测试及新增对抗用例验证结构和权限，尚不能保证语义正确或完全遗忘。详见 [对抗式审核报告](ADVERSARIAL_REVIEW.md)。独立静态记忆地图支持本地导入，开通见 [GitHub Pages说明](GITHUB_PAGES.md)。
