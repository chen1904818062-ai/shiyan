# 开放注册前的账号配置

拾言 v1.1.0 支持邮箱和中国大陆 +86 手机验证码登录。首次验证创建独立账号；在「我的账号」绑定第二种方式后，手机和邮箱进入同一空间。新实例默认 `APP_PUBLIC_SIGNUP=false`，先完成真实收码验证再开放。

现有 Render 服务的 Environment 是配置来源。以下只配置拾言服务，密钥不进入代码、聊天或前端。

2026-10-19 当前拾言服务已完成 Resend 配置和真实邮箱验证码绑定验收。发件地址为 `拾言 <login@mail.tongpinlab.cn>`，独立密钥 `shiyan-signin-live` 仅有该域名的发送权限，凭证仅存于 Render。`APP_AUTH_SECRET` 已生成并保留，`APP_PUBLIC_SIGNUP=true` 开放邮箱登录注册。腾讯云短信尚未配置，手机页明确显示未开放。下面的步骤供新部署或更换凭证使用，不需要重复生成当前系统密钥。

## Resend 邮箱

在 [拾言 Render 环境设置](https://dashboard.render.com/web/srv-dbadkqvbtjjs73eoft30/env) 填写：

| 变量 | 内容 |
| --- | --- |
| `APP_AUTH_SECRET` | 至少32字符的稳定随机密钥，供验证码摘要使用，不是登录密码；不要频繁替换 |
| `RESEND_API_KEY` | Resend 发送权限密钥 |
| `AUTH_EMAIL_FROM` | 例如 `拾言 <login@你的已验证域名>` |
| `APP_PUBLIC_SIGNUP` | 先保持 `false` |

发件地址须使用已在 Resend 验证的域名。测试发件域名不能直接用于面向其他用户的注册邮件。参考 [发送 API](https://resend.com/docs/api-reference/emails/send-email) 和 [域名配置](https://resend.com/docs/dashboard/domains/introduction)。

保存并部署后，用原访问密码进入拾言，点击侧栏「我的账号」。管理员区可查看配置是否存在，不显示密钥值。在邮箱页填写自己的邮箱并获取验证码；收到后输入，点击「验证并绑定」。已有话题、原文和报告保留在原 owner ID 下。

绑定成功后，将 `APP_PUBLIC_SIGNUP=true` 保存并部署，才开放公共验证码登录。已绑定邮箱回到原空间，新邮箱进入独立空空间。原空间绑定后停用旧密码登录；尚未绑定时可在 `/owner/login` 使用原密码，随后绑定手机或邮箱。不要将原访问密码分享给新用户。

## 腾讯云短信

启用腾讯云短信、创建应用、完成国内签名与模板审核后设置：

| 变量 | 内容 |
| --- | --- |
| `TENCENT_SMS_SECRET_ID` | 具有短信发送权限的凭证 ID |
| `TENCENT_SMS_SECRET_KEY` | 对应密钥 |
| `TENCENT_SMS_APP_ID` | 短信应用 SDK AppID |
| `TENCENT_SMS_SIGN_NAME` | 已审核签名正文，非签名 ID |
| `TENCENT_SMS_TEMPLATE_ID` | 已审核国内验证码模板 ID |

模板只包含一个参数（6位验证码），固定正文注明5分钟有效，例如「你的验证码为{1}，5分钟内有效，请勿泄露」。应用只传一个模板参数。参见 [腾讯云 SendSms 文档](https://cloud.tencent.com/document/api/382/55981)。

短信未配置时，手机页说明尚未开放，不会假装发送成功；邮箱可独立开放。短信配置后也需验证真实收码。

## 行为及验证范围

- 验证码安全随机生成，5分钟过期、一次使用、最多5次猜测，绑定请求浏览器和用途。数据库仅保存密钥摘要，不保存、打印或回传明文验证码。
- 发送冷却60秒，每个目标每小时最多8次；每个连接来源每15分钟最多20次发送、50次验证。另有目标验证频控，以及跨进程和重启的全局发送额度，`AUTH_DAILY_SEND_LIMIT` 默认每滚动24小时200次（短信邮件合计）。代理环境下连接来源可能共享额度，初期适用于小范围开放。
- 会话8小时，HttpOnly Cookie，生产 HTTPS 下启用 Secure 与 __Host- 前缀。写请求校验同源，退出仅注销当前会话。
- 用户数据按账号隔离。其他用户在模型设置中填写自己的 Key，不能借用原空间服务端模型 Key。
- 不合并两个分别注册的账号。请登录需要保留的账号，再绑定另一种方式；当前不支持解绑或直接替换已绑定地址。
- 备份格式 v2 包含账号、已验证手机号/邮箱及话题原文报告，不含会话、验证码和服务密钥。备份有个人资料，应受保护。支持导入旧 v1 数据；目标必须为空。生产导出前暂停写入，迁移后重新配置发送服务和 APP_AUTH_SECRET。
- 自动测试使用测试专用发送适配器，覆盖验证码登录、错误码、过期和重放、绑定、双账号越权、备份恢复、桌面和手机显示，不能代表真实邮件短信已经送达。生产中没有固定验证码、调试收码接口或认证旁路。

变量更改需相应部署后才生效，参见 [Render 环境变量说明](https://render.com/docs/configure-environment-variables)。`APP_PUBLIC_SIGNUP=false` 会关闭普通用户验证码登录和注册，但保留现有会话及内容，适用于维护。
