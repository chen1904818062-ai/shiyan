如何理解这张地图

连接按已存储的话题和类型建立，不自动推断亲密关系、人格或职业适合度。时间线只使用明确记录的发生日期；未记录的日期单独呈现。“已确认”表示用户核对过记录，不代表外部事实已获验证。

为保持流畅，单次地图与时间线最多显示 200 条；概览统计基于当前筛选结果。可以用关键词或状态缩小范围。支持最多 2,000 条、10 MB 的拾言个人导出文件，不接收管理员整库备份。
